## 📋 Описание

**Yandex SERP Collector** - продвинутый инструмент для автоматизированного сбора поисковой выдачи Яндекса. Разработан для сбора данных по различным ключевым фразам с возможностью глубокого анализа результатов, фильтрации и экспорта.

Отличительные особенности:
- 🚀 **Многопоточный сбор** - одновременная обработка до 3 запросов
- 🔄 **Интеллектуальное восстановление** после сбоев и обработка капчи
- 🧠 **Умное распознавание капчи** - комбинированный подход с автоматическим и ручным решением
- 💾 **Сохранение контрольных точек** - возможность продолжить прерванный сбор данных
- 📊 **Расширенная фильтрация** результатов по релевантности
- 🧩 **Модульная архитектура** - легкое расширение функциональности

## 🚀 Быстрый старт

### Установка

```bash
# Клонирование репозитория
git clone https://github.com/SergD/yandex-serp-collector.git
cd yandex-serp-collector

# Установка зависимостей
npm install
```

### Настройка

1. Создайте файл `.env` в корневой директории:
```
REGION_PARAM=108975  # Код региона Яндекса (по умолчанию Москва)
THREADS_COUNT=3      # Количество одновременных потоков
RETRY_COUNT=2        # Количество повторных попыток для неудачных запросов
```

### Запуск

```bash
# Стандартный запуск со всеми запросами
node src/yandex-collector.js

# Тестовый режим с одним запросом
node src/yandex-collector.js --test

# Запуск с указанием файла запросов
node src/yandex-collector.js --queries-file=my-queries.json
```

## 🧰 Расширенные возможности

### Многопоточный сбор

Система автоматически распределяет все запросы на указанное количество потоков (по умолчанию 3), что значительно ускоряет сбор данных:

```javascript
// Пример конфигурации в .env
THREADS_COUNT=3
```

### Автоматическое восстановление

При сбоях, система:
- Сохраняет промежуточные результаты
- Запоминает необработанные запросы
- Автоматически повторяет неудачные запросы
- Может возобновить работу с места прерывания

### Расширенная фильтрация

Возможность настроить фильтрацию результатов:
- По релевантным ключевым словам
- По исключению определенных доменов
- По типу результатов (органика, реклама)

### Обработка капчи

Система использует комбинированный подход к решению капчи Яндекса:
- Автоматические клики по чекбоксу
- Интеграция с сервисом 2captcha (опционально)
- Возможность ручного решения с минимальной задержкой

## 📊 Формат результатов

Все результаты сохраняются в формате JSON:

```json
[
  {
    "title": "Кредиты для ИП и малого бизнеса в 2025 году — СберБизнес",
    "url": "https://www.sberbank.ru/ru/s_m_business/credits",
    "domain": "sberbank.ru",
    "snippet": "Кредиты для ИП и малого бизнеса от Сбера — выгодные условия...",
    "pagePosition": 1,
    "globalPosition": 1,
    "query": "кредит для ИП",
    "isRelevant": true
  },
  ...
]
```

## 🧩 Расширение функциональности

Благодаря модульной архитектуре, можно легко добавлять новые возможности:

```javascript
// Пример добавления нового обработчика результатов
const parseSearchResults = require('./src/searchQueryWithPagination');

// Настройка кастомной фильтрации
const customFilter = (result) => {
  return result.title.includes('кредит') && !result.domain.includes('sberbank.ru');
};

// Использование
const results = await parseSearchResults(page, 0, customFilter);
```
